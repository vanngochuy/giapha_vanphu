# Project: Van Phu Genealogy Web System (Gia Phả Họ Văn Phú)

## 1. System Architecture
This project is a web-based interactive genealogy tree management system.
- **Backend Stack:** Python (FastAPI or Flask) to ensure lightweight and high-performance API handling.
- **Database:** PostgreSQL for recursive queries (CTE) required by hierarchical family tree data.
- **Frontend Stack:** HTML/JS/CSS with D3.js or FamilyTreeJS for rendering the interactive genogram.
- **Export Service:** Server-side PDF generation using Headless Chrome/Puppeteer to ensure print-quality vector outputs.

## 2. Core Features required from Agent
- Parse and seed data from existing CSV/Google Sheets format.
- Create robust CRUD APIs for family members.
- Implement a visually striking, interactive graph visualization on the frontend (Pan, Zoom, Expand/Collapse nodes).
- Implement a high-resolution export to PDF endpoint.

## 3. Directory Structure Guidelines
- `/backend`: Python API, models, routes.
- `/frontend`: Static assets, UI components, Graph visualization logic.
- `/database`: Migration scripts and seed data.
- `/services`: Third-party or heavy processing modules (e.g., PDF export).
