# Database Schema Requirements

## 1. Core Table: `family_members`
The agent must generate SQLAlchemy (or raw SQL) models for PostgreSQL using the following strict schema:

| Column Name           | Data Type    | Constraints                  | Description |
|-----------------------|--------------|------------------------------|-------------|
| `id`                  | VARCHAR(20)  | PRIMARY KEY                  | E.g., 'VP-001' |
| `parent_id`           | VARCHAR(20)  | FOREIGN KEY (`id`), NULLABLE | Self-referencing link for the tree |
| `full_name`           | VARCHAR(100) | NOT NULL                     | Member's full name |
| `generation`          | INTEGER      | NOT NULL                     | Generation level (1, 2, 3...) |
| `branch_name`         | VARCHAR(50)  | NULLABLE                     | E.g., 'Phái Nhất - Nhánh 1' |
| `status`              | VARCHAR(20)  | DEFAULT 'Còn sống'           | 'Còn sống' / 'Đã mất' |
| `birth_year`          | VARCHAR(10)  | NULLABLE                     | Year of birth |
| `death_date_lunar`    | VARCHAR(20)  | NULLABLE                     | Lunar death date for anniversary |
| `burial_place`        | TEXT         | NULLABLE                     | GPS or text location |
| `notes`               | TEXT         | NULLABLE                     | Biography or extra info |

## 2. Recursive Query Requirement
When querying the tree, the backend API must utilize PostgreSQL Common Table Expressions (WITH RECURSIVE) to fetch the hierarchy efficiently in a single database hit, returning a nested JSON structure to the frontend.
